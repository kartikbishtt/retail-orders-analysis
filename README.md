# Retail Orders Analysis

An exploratory data analysis project using Python and Pandas to analyze retail order data.

## Project Overview

This project analyzes retail sales data to identify patterns across customers, products, categories, regions, order segments, discounts, quantities, and sales performance.

## Dataset

The dataset contains retail order-level information including:

- Order and shipping dates
- Ship mode
- Customer segment
- Country, city, state and region
- Product category and sub-category
- Product ID
- Cost and list price
- Quantity
- Discount percentage

## Analysis

The project performs exploratory data analysis to examine:

- Sales and order patterns
- Product and category performance
- Regional performance
- Customer segments
- Discounts
- Quantity and pricing patterns
- Other relationships within the retail dataset

## Tools

- Python
- Pandas
- Jupyter Notebook
